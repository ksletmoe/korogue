cp437_10x10.png

Source:  AsciiPanel, by Trystan Spangler — https://github.com/trystan/AsciiPanel
         One of AsciiPanel's bundled "system" CP437 fonts (its README lists
         CP437_8x8/10x10/12x12/16x16/9x16 as provided fonts). The bytes in this
         copy were re-exported on macOS (so the PNG carries an Apple ICC profile),
         but the glyph pixels are identical to AsciiPanel's cp437_10x10.png —
         verified with a pixel diff (0 differing pixels).
