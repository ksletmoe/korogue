Source:  AsciiPanel, by Trystan Spangler — https://github.com/trystan/AsciiPanel
         These are AsciiPanel's own bundled CP437 "system" fonts (its README
         lists CP437_8x8/9x16/10x10/12x12/16x16 as provided fonts). Each is a
         16x16 CP437 grid, code point 0 top-left, crisp 1-bit (black background,
         white glyphs) — loaded with keyColor = Color.BLACK so the black keys to
         transparent (see Fonts.cp437_*()).
