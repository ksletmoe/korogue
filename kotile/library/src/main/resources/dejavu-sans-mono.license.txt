fonts/DejaVuSansMono-Bold.ttf

Source:  DejaVu Sans Mono (Bold), by the DejaVu fonts project —
         https://dejavu-fonts.github.io
         A monospaced typeface with COMPLETE CP437 coverage: all 253 distinct
         code points a code-page-437 grid needs — box-drawing (U+2500–257F),
         block elements and shades (U+2580–259F), the control-range symbols,
         arrows, Greek, math, and accented ranges — none falling back to
         .notdef. Bundled as an alternative to the default Cascadia Mono
         (Fonts.dejaVuSansMono; selected in krogue-9x7.8 / ADR-0039): a wider,
         heavier, more neutral letterform than Cascadia. The Bold weight is
         bundled for the same downscale-crispness reason.
