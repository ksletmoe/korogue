fun overlaps(other: IntRect, padding: Int = 0): Boolean

Returns true if this rect and other intersect once this rect is inflated by padding on every side — i.e. true if the two rects are closer than padding apart, not just overlapping outright. padding = 0 is a plain AABB intersection test.
