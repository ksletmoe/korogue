class Paginator<T>(items: List<T>, pageSize: Int)

A headless, generic page model: splits items into pages of at most pageSize and tracks which page is current, with forward/back navigation. Pure logic — no rendering, no input handling, no libGDX — so it can drive any presentation (a PagedTextList, a custom widget, or a test) and the caller stays in full control of how a page looks and which keys turn it.
