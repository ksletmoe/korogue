StandardSystems

data class StandardSystems(val scheduler: SchedulerSystem?, val rangedAttack: RangedAttackSystem, val behavior: BehaviorSystem, val movement: MovementSystem, val portal: PortalSystem, val pickup: PickupSystem, val combat: CombatSystem, val lighting: LightingSystem, val perception: PerceptionSystem)(source)

The systems installStandardSystems registered, handed back so the caller can hold the ones it needs to drive outside the tick loop — lighting and perception in particular, since a host typically runs them once at startup so the first frame isn't black before any turn has been taken (see the demo's initial-lighting pass).
