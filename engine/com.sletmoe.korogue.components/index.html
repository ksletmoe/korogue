data class AttackIntent(val targetId: EntityId) : Component

A pending melee attack on targetId, emitted by MovementSystem when a MoveIntent is blocked by an occupied cell and resolved by CombatSystem. The attacker is the entity that holds the component.

Behavior

@Serializable
@SerialName(value = "behavior")
data class Behavior(val strategyId: String) : Component

Drives an entity's AI. strategyId names a behavior resolved via the GameModule strategy registry (e.g. wander, hunt-player); BehaviorSystem runs it each tick to emit a MoveIntent. Stored by stable id rather than a strategy object so the component stays serializable (the registry convention from ARCHITECTURE.md; general registry arrives with 4f).

MoveIntent

data class MoveIntent(val dx: Int, val dy: Int) : Component

A pending request to move by (dx, dy) this tick. Movement is data: player input and AI attach a MoveIntent; MovementSystem resolves and consumes it (a step onto walkable terrain, a bump-attack on an occupant, or a no-op into a wall).
