GameModule

class GameModule(source)

The single seam describing a game's pluggable pieces to the engine (ADR-0009, hybrid option iii). It bundles the per-concern registries — strategies (AI), calculators (lighting), senses / perceptionModels (perception, ADR-0015), generators (world-gen, ADR-0019), and components (serialization) — so a consumer configures everything in one place (GameModule.engineDefaults().strategy(...).component<Foo>().build()), while systems and the save codec each depend only on the narrow registry they need, never the whole module.
