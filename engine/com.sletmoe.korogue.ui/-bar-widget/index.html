BarWidget

class BarWidget(val bounds: IntRect, label: String, filled: Color, empty: Color, labelColor: Color = Color.WHITE, z: Int = 0, value: () -> BarValue) : Widget(source)

A single-row stat bar (ADR-0011): LABEL ████████░░ cur/max. Reads its value each frame (via the supplied function) so it always reflects live state — point it at the player's health for an HP bar, mana for a mana bar, etc. Filled cells use filled, the remainder empty.

Drawn on the bar's own row (y = 0 of its bounds); the bar shrinks to fit between the label prefix and the cur/max suffix, and a zero/negative max renders empty rather than dividing.
