fun dimmedRememberedRenderer(dimFactor: Double = PREVIOUSLY_VIEWED_DIM_FACTOR, blueBoost: Float = PREVIOUSLY_VIEWED_BLUE_BOOST, background: Color = Color.BLACK): (Tile) -> MapPanel.RenderedCell

A rememberedRenderer that dims a remembered tile's foreground to a dark tint on background, the engine's default look. dimFactor scales the lit foreground (lower = darker) and blueBoost adds a cool cast; a game that only wants remembered terrain brighter/warmer can pass its own values without writing the tint math itself.
