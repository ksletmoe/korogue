LightFlicker

@Serializable
data class LightFlicker(val amplitude: Double = 0.15, val periodMs: Long = 400, val seed: Long = 0)(source)

Presentation-side flicker descriptor for a com.sletmoe.korogue.components.LightEmitter (krogue-ncl, ADR-0023's presentation-time axis): a wall-clock intensity modulation, layered on top of the tick-computed Zone.lightMap at render time — never recomputed into the saved light field itself. Attaching one is opt-in; an emitter with no LightEmitter.flicker renders exactly as before (a steady circle).

Only amplitude and periodMs are static config (saved as part of the emitter, like color/ radius); the actual flicker value is a pure function of wall-clock time, computed fresh by factorAt every frame and never persisted.
