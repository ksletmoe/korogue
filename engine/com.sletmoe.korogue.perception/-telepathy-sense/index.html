TelepathySense

class TelepathySense : Sense

{mental} sense: reveals living creatures (those with Health) within Telepathy.radius — the whole zone when null — ignoring walls, line-of-sight, and lighting. Like TremorsenseSense it perceives minds, not terrain, so it contributes entities only.

pierces

open val pierces: Set<String>

Concealment tags this sense sees through despite a match (e.g. see-invisible / true-sight). Piercing defeats target-side concealment only — it does not override an observer's Suppressor (ADR-0015): a blinded {visual} sense is dropped however much it pierces, because a suppressor disables the channel the sense runs on. Immunity to a suppressor comes from being on a channel it doesn't negate (a non-{visual} sense survives Blind), not from piercing.
