GameWorld
Link copied to clipboard
open class GameWorld(val ecs: World, val zones: Map<String, Zone>, _currentZoneId: String)

The krogue game world: the ECS World (all entities + systems) composed with the zone registry (terrain by id + the current zone). Per ADR-0007, GameWorld composes ecs.World rather than merging, so the ECS core stays game-agnostic; zones and tiles are krogue concepts that live here.

GdxColorSerializer

object GdxColorSerializer : KSerializer<Color>

Serializes a libGDX Color as a packed RGBA8888 Int — compact and lossless for the 8-bit colours tiles use. Lets Tile be @Serializable despite holding a non-serializable GDX type (4f).

Zone
Link copied to clipboard
open class Zone(val zoneId: String, val tiles: Grid<Tile>)

Terrain for one map: its tile grid, bounds, and a derived light map. Occupants (creatures, the player, light emitters) are ECS entities tagged with ZoneMember and owned by GameWorld.ecs — a Zone no longer holds them (ADR-0007, 4b-s3).
